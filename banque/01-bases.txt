// Banque de questions — chapitres 00 à 07 : les bases du langage PHP
// Format : voir banque/README.md   ([cours] = notion tirée d'un cours, voir SOURCES.md)

# 00

Q: Où le code PHP est-il exécuté quand une page est demandée ?
+ Sur le serveur, avant l'envoi de la réponse au navigateur
- Dans le navigateur, juste après le chargement de la page
- Sur le poste de l'utilisateur, grâce à un moteur intégré
- Dans la base de données, au moment de la requête SQL
? PHP est un langage exécuté côté serveur : le navigateur ne reçoit que le résultat (généralement du HTML), jamais le code PHP.

Q: Dans « Afficher le code source » du navigateur, que voit-on d'un script PHP ?
+ Uniquement le HTML produit, jamais les balises <?php
- Le code PHP complet, avec ses variables et ses commentaires
- Le code PHP, mais avec la valeur des variables à la place des noms
- Seulement les commentaires PHP laissés par le développeur
? Le serveur exécute le PHP et n'envoie que le résultat : le code source reste côté serveur.

Q: Que fait la commande « php -l fichier.php » ?
+ Elle vérifie la syntaxe (lint) sans exécuter le script
- Elle exécute le script en affichant chaque ligne traitée
- Elle liste tous les fichiers PHP présents dans le dossier
- Elle démarre un serveur local pour ce fichier précis
? « -l » signifie lint : PHP analyse la syntaxe et signale les erreurs sans rien exécuter. À lancer sur chaque fichier avant de le rendre ou de le publier.

Q: Quelle commande démarre le serveur web intégré de PHP sur le port 8000 ?
+ php -S localhost:8000
- php serve localhost:8000
- php --run 8000
- php -L localhost:8000
? « php -S adresse:port » (S majuscule) lance le serveur de développement. Option « -t dossier » pour choisir la racine (ex : -t public).

Q: Que produit <?= $titre ?> ?
+ La même chose que <?php echo $titre; ?>
- La même chose que <?php return $titre; ?>
- La même chose que <?php var_dump($titre); ?>
- Une erreur : la balise n'existe plus
? <?= expression ?> est le raccourci d'écriture de echo, très utilisé dans les gabarits HTML.

Q: Quel opérateur concatène deux chaînes en PHP ?
+ Le point (.)
- Le plus (+)
- L'esperluette (&)
- Le double deux-points (::)
? En PHP la concaténation est le point. Le + est arithmétique : avec une chaîne non numérique il lève un TypeError en PHP 8.

Q: Un point-virgule oublié à la fin d'une instruction provoque généralement…
+ Une « Parse error » souvent signalée à la ligne suivante
- Un « Warning: Undefined variable » à la ligne de l'oubli
- Une réponse HTTP 404 renvoyée par le serveur intégré
- Aucune erreur : PHP rajoute le point-virgule tout seul
? PHP lit l'instruction suivante comme la suite de la précédente et détecte l'erreur une ligne plus loin : on regarde la ligne signalée ET celle d'avant.

Q: Que signifie « Warning: Undefined variable $age » ?
+ $age est utilisée avant d'avoir reçu une valeur
- $age a reçu une valeur d'un type incompatible
- $age est déclarée mais n'est jamais affichée
- $age porte le même nom qu'une fonction existante
? Une variable doit être affectée avant d'être lue. Le script continue (c'est un avertissement), mais la valeur utilisée est null : le résultat est presque toujours faux.

Q: Dans un fichier qui ne contient que du PHP, que fait-on de la balise fermante ?
+ On l'omet, pour ne pas envoyer d'espace parasite
- On la place toujours, sinon le fichier ne s'exécute pas
- On la remplace par une balise de fermeture <?end>
- On la met en première ligne, avant la balise ouvrante
? Un espace ou un retour à la ligne après ?> serait envoyé au navigateur, donc avant les en-têtes HTTP.

Q: PHP signale une erreur de syntaxe à la ligne 12. Où commencer à chercher ?
+ Ligne 12 et la ligne juste avant
- Uniquement à la ligne 12, jamais ailleurs
- Dans la feuille de style CSS du site
- Dans le fichier de configuration php.ini
? Méthode de débogage : lire le message en entier, noter le type d'erreur, regarder la ligne signalée et la précédente, corriger une seule chose à la fois.

Q: Que contient la constante prédéfinie PHP_VERSION ?
+ La version de PHP qui exécute le script
- La version du navigateur de l'utilisateur
- La version du serveur de base de données
- La version du système d'exploitation hôte
? PHP_VERSION permet par exemple d'afficher dans la page la version de PHP qui exécute le script.

Q: Parmi ces situations, lesquelles provoquent une erreur ou un avertissement PHP ?
+ Un guillemet ouvert jamais refermé
+ Utiliser $x avant de lui avoir donné une valeur
- Écrire un commentaire avec //
- Mettre un espace avant le signe =
? Une chaîne non fermée donne une Parse error ; une variable non définie donne un Warning. Les commentaires et les espaces sont inoffensifs.

Q: Quelle différence y a-t-il entre var_dump() et print_r() ?
+ var_dump affiche aussi le type de chaque valeur ; print_r seulement les valeurs
- print_r affiche le type de chaque valeur ; var_dump seulement les valeurs
- var_dump ne sait afficher que des tableaux, print_r que des chaînes
- Aucune : ce sont deux noms de la même fonction de débogage
? var_dump("5") affiche string(1) "5", alors que print_r("5") affiche seulement 5. Pour comprendre un problème de type, var_dump est plus précis. print_r($t, true) renvoie le texte au lieu de l'afficher.

Q: Lesquels de ces noms sont insensibles à la casse en PHP ?
+ Les noms de fonctions : strlen et STRLEN
+ Les mots-clés du langage : echo et ECHO
- Les noms de variables : $nom et $Nom
- Les clés de tableau : 'id' et 'ID'
? Variables, clés de tableau et constantes sont sensibles à la casse ; fonctions, méthodes, classes et mots-clés ne le sont pas. On écrit tout de façon cohérente pour éviter les surprises.

Q: Pourquoi ne jamais laisser une page qui appelle phpinfo() en ligne ?
+ Elle révèle la configuration : versions, chemins, extensions, variables
- Elle ralentit toutes les autres pages du site tant qu'elle existe
- Elle désactive l'affichage des erreurs dans tout le reste du site
- Elle permet de modifier le fichier php.ini depuis le navigateur
? phpinfo() est pratique en local pour vérifier une extension ou un réglage, mais ces informations aident un attaquant à cibler une faille connue.

Q: Quelles syntaxes de commentaire sont valides dans un bloc PHP ?
+ // commentaire jusqu'à la fin de la ligne
+ /* commentaire sur plusieurs lignes */
+ # commentaire jusqu'à la fin de la ligne
- <!-- commentaire --> comme en HTML
? // et # commentent jusqu'à la fin de la ligne, /* … */ un bloc entier. <!-- --> est un commentaire HTML : à l'intérieur de <?php … ?>, c'est une erreur de syntaxe.

Q: Que signifie « Fatal error: Uncaught Error: Call to undefined function afficher() » ?
+ La fonction n'existe pas : faute de frappe ou fichier qui la déclare non inclus
- La fonction existe mais a reçu trop d'arguments lors de l'appel
- La fonction est déclarée plus bas dans le même fichier que l'appel
- La fonction ne retourne aucune valeur alors qu'un echo l'attend
? On vérifie l'orthographe et le require du fichier qui la déclare. Une fonction déclarée plus bas dans le même fichier (hors d'un if) peut être appelée avant sa déclaration.

Q: Quelle différence y a-t-il entre echo et print ?
+ echo accepte plusieurs arguments ; print un seul, et renvoie toujours 1
- print accepte plusieurs arguments ; echo un seul, et renvoie toujours 1
- print ajoute un retour à la ligne final ; echo n'en ajoute jamais
- echo est une fonction à appeler avec des parenthèses ; print un mot-clé
? Ce sont deux constructions du langage, sans parenthèses obligatoires. echo 'a', 'b'; est valide. print renvoie 1, ce qui permet (rarement) de l'utiliser dans une expression.

# 01

Q: Quel est le type de la valeur 8.5 en PHP ?
+ float
- int
- string
- decimal
? Les nombres à virgule sont des float et s'écrivent avec un point décimal (jamais une virgule).

Q: Pourquoi stocker l'année 1979 comme entier plutôt que comme la chaîne "1979" ?
+ Un entier se compare, se trie et se calcule correctement
- PHP interdit de mettre des chiffres entre guillemets
- Une chaîne est trop lente pour être affichée avec echo
- Un entier prend moins de place qu'une chaîne en base
? Les types portent du sens : on veut pouvoir faire $annee >= 1990 ou $annee + 1. Une chaîne se trierait alphabétiquement.

Q: Pourquoi le prix doit-il valoir 3.99 plutôt que "3,99 €" ?
+ Le symbole et la virgule sont de l'affichage, pas de la donnée
- PHP refuse d'enregistrer un symbole monétaire dans une variable
- La virgule est réservée à la séparation des éléments d'un tableau
- Un float prend toujours moins de place qu'une chaîne en mémoire
? Règle d'or : calculer avec des nombres, formater (number_format) uniquement au moment de l'affichage.

Q: Que produit var_dump("1979"); ?
+ string(4) "1979"
- int(1979)
- string(1979)
- float(1979)
? var_dump affiche le type ET la valeur. Les guillemets font de 1979 une chaîne de 4 caractères.

Q: Que produit var_dump(10 / 2); en PHP 8 ?
+ int(5)
- float(5)
- int(2)
- string(1) "5"
? L'opérateur / renvoie un int quand la division tombe juste (10 / 2) et un float sinon (7 / 2 donne float(3.5)).

Q: Que retourne intdiv(7, 2) ?
= 3
? intdiv renvoie le quotient entier (7 = 2 × 3 + 1).

Q: Que vaut 2 ** 10 ?
= 1024
? ** est l'opérateur de puissance (2 puissance 10).

Q: Que fait declare(strict_types=1); placé en tête d'un fichier ?
+ Il refuse les conversions implicites de type lors des appels (TypeError)
- Il active l'affichage détaillé de toutes les erreurs et avertissements
- Il impose de déclarer le type de chaque variable du fichier
- Il bloque l'usage des chaînes de caractères dans les calculs
? Sans lui, f("5") pour un paramètre int est converti silencieusement ; avec lui, c'est un TypeError. Cela évite des bugs discrets.

Q: Que vaut 0.1 + 0.2 === 0.3 en PHP ?
+ false
- true
- null
- Une erreur de syntaxe
? Les float sont stockés en binaire et 0.1 + 0.2 donne 0.30000000000000004. Pour comparer des float, on utilise une tolérance ; pour l'argent, on travaille en centimes (entiers).

Q: Que retourne (int) "12abc" ?
= 12
? Le cast lit les chiffres du début de la chaîne et s'arrête au premier caractère non numérique.

Q: Laquelle de ces valeurs est considérée comme vraie (truthy) dans une condition ?
+ "false" (la chaîne de texte)
- "0" (la chaîne zéro)
- [] (le tableau vide)
- 0.0 (le flottant nul)
? Sont « falsy » : false, 0, 0.0, "", "0", [] et null. La chaîne "false" est une chaîne non vide et différente de "0" : elle est vraie.

Q: Que se passe-t-il avec intdiv(1, 0) ?
+ Une DivisionByZeroError est lancée
- Le résultat vaut 0
- Le résultat vaut INF
- Un simple avertissement apparaît
? En PHP 8, la division par zéro (/, intdiv, %) lance une DivisionByZeroError.

Q: Quelles valeurs sont de type float ?
+ 8.5
+ 1e3
- "8.5"
- 8
? 1e3 vaut 1000.0 (notation scientifique, float). "8.5" est une chaîne, 8 est un entier.

Q: $Titre et $titre désignent…
+ Deux variables distinctes : la casse compte
- La même variable : PHP ignore la casse des noms
- La même variable, avec un avertissement à l'affichage
- Une erreur de syntaxe qui arrête le script
? Les noms de variables sont sensibles à la casse (les noms de fonctions ne le sont pas).

Q: Que retourne number_format(1234.5, 2, ',', ' ') ?
+ 1 234,50
- 1,234.50
- 1234.5
- 1.234,5
? number_format(nombre, décimales, séparateur décimal, séparateur de milliers).

Q: Que fait $nombreFilms++; ? [cours]
+ Il ajoute 1 à $nombreFilms (comme $nombreFilms = $nombreFilms + 1)
- Il double la valeur de $nombreFilms à chaque exécution du script
- Il crée une copie indépendante de la variable $nombreFilms
- Il affiche la valeur de $nombreFilms puis supprime la variable
? ++ est l'opérateur d'incrémentation ; -- décrémente ; += ajoute une valeur quelconque.

Q: Avec $dureeMinutes = 117, que valent $heures = (int) ($dureeMinutes / 60); et $minutes = $dureeMinutes % 60; ? [cours]
+ 1 heure et 57 minutes
- 2 heures et 3 minutes
- 1 heure et 17 minutes
- 117 heures et 0 minute
? 117 / 60 = 1,95 → (int) tronque à 1 ; 117 % 60 = 57 (reste de la division).

Q: Quelle différence y a-t-il entre une constante déclarée avec const et une variable ?
+ La constante s'écrit sans $ et ne peut plus être réaffectée
- La constante n'existe qu'à l'intérieur de la fonction qui la déclare
- La constante peut changer de valeur, mais une seule fois par script
- La constante ne peut contenir qu'un nombre entier, jamais du texte
? const TVA = 0.2; puis echo TVA;. Une constante est sensible à la casse et sa valeur est fixée une fois pour toutes. define('TVA', 0.2) fonctionne aussi, y compris à l'intérieur d'un if.

Q: Que retourne get_debug_type(3.0) ?
= float
? get_debug_type donne le nom du type tel qu'on l'écrit dans une déclaration : int, float, string, bool, null, array ou le nom de la classe. gettype(3.0) renvoie « double », un nom historique.

Q: Que produit var_dump(PHP_INT_MAX + 1); ?
+ Un float : un entier qui déborde devient un nombre à virgule
- Un int négatif : la valeur repart de PHP_INT_MIN
- Une OverflowException qui arrête le script
- Le même int : PHP_INT_MAX ne peut jamais être dépassé
? PHP ne lève pas d'erreur : le résultat devient un float (9.2233720368547758E+18), avec une perte de précision possible.

Q: Que vaut "5" + "3" en PHP ?
+ int(8) : + est toujours arithmétique, les chaînes numériques sont converties
- string(2) "53" : le + concatène deux chaînes de caractères
- Une TypeError : l'opérateur + n'accepte pas de chaînes
- float(8) : toute conversion de chaîne produit un flottant
? En PHP, + additionne et . concatène : "5" . "3" donne "53". C'est une différence importante avec JavaScript, où "5" + "3" vaut "53".

Q: Que se passe-t-il avec "abc" + 1 en PHP 8 ?
+ Une TypeError : une chaîne non numérique ne peut pas être additionnée
- Le résultat vaut 1 avec un simple avertissement, comme en PHP 7
- Le résultat vaut "abc1", car le + concatène deux valeurs
- Le résultat vaut 0, car la chaîne est convertie en zéro
? « Unsupported operand types: string + int ». Une chaîne qui COMMENCE par des chiffres ("10 pommes" + 5) donne 15 avec un Warning « A non-numeric value encountered ».

Q: Que vaut -7 % 3 en PHP ?
= -1
? Le résultat de % prend le signe du premier opérande : -7 = 3 × (-2) - 1. À l'inverse, 7 % -3 vaut 1.

Q: Que retourne round(2.5) en PHP ?
= 3
? Par défaut, round arrondit la moitié « en s'éloignant de zéro » : round(2.5) vaut 3 et round(-2.5) vaut -3. floor arrondit vers le bas, ceil vers le haut.

Q: Que valent $a et $b à la fin de ce code ?
|$i = 5;
|$a = $i++;
|$b = ++$i;
+ $a = 5 et $b = 7
- $a = 6 et $b = 6
- $a = 5 et $b = 6
- $a = 6 et $b = 7
? $i++ renvoie l'ancienne valeur puis incrémente ($a = 5, $i = 6) ; ++$i incrémente puis renvoie la nouvelle valeur ($i = 7, $b = 7).

Q: Quel opérateur affecte une valeur seulement si la variable (ou la clé) est absente ou vaut null ?
= ??=
? $t['page'] ??= 1; équivaut à $t['page'] = $t['page'] ?? 1;. Une valeur 0 ou "" déjà présente est conservée.

Q: Lesquelles de ces chaînes sont acceptées par is_numeric() ?
+ "42"
+ "-3.5"
+ "1e3"
- "12abc"
- "0x1A"
? is_numeric accepte un signe, des décimales, la notation scientifique et des espaces autour. Il refuse le texte mélangé aux chiffres et la notation hexadécimale.

# 02

Q: Quelle différence entre == et === ?
+ === compare aussi le type, == fait des conversions
- Aucune, ce sont des synonymes
- == compare les types, === compare les valeurs
- === ne s'applique qu'aux chaînes
? Préférer === pour éviter les conversions surprenantes (voir le piège 0 == "a").

Q: Qu'affiche echo 2 <=> 5; ?
= -1
? L'opérateur « vaisseau spatial » renvoie -1, 0 ou 1 selon que le premier opérande est plus petit, égal ou plus grand. Très utile dans usort.

Q: Dans if (isset($t['x']) && $t['x'] > 3), que se passe-t-il si la clé 'x' est absente ?
+ La 2e condition est ignorée (évaluation paresseuse) : aucun Warning
- Un Warning « Undefined array key » apparaît à la 2e condition
- Une exception TypeError est levée avant la fin du test
- La condition entière est considérée comme vraie par défaut
? && s'arrête dès qu'un opérande est faux. D'où l'habitude de placer isset() en premier.

Q: Quelle différence entre match et switch ?
+ match compare en strict, renvoie une valeur et lève UnhandledMatchError sans cas
- match compare en lâche (==) comme switch, mais avec une syntaxe plus courte
- match n'accepte que des chaînes et exige un break après chaque cas
- match s'exécute plus lentement mais gère le fall-through automatiquement
? match est une expression, plus sûre : pas de fall-through, comparaison stricte, erreur si cas oublié (sans default).

Q: Que retourne empty("0") ?
+ true
- false
- Une erreur
- null
? La chaîne "0" est falsy, donc empty() la considère comme vide. Attention aux champs de formulaire contenant un 0 légitime.

Q: Qu'affiche echo 0 ?? 'x'; ?
= 0
? ?? ne remplace la valeur que si elle est absente ou null. 0 est conservé (contrairement à l'opérateur ?: qui testerait la « falsyté » et donnerait 'x').

Q: Dans un switch, que se passe-t-il si un case n'a pas de break ? [cours]
+ L'exécution continue dans le case suivant (fall-through)
- PHP signale une erreur de syntaxe et arrête le script
- Le switch s'arrête quand même à la fin de ce case
- Le case suivant est ignoré et PHP passe au default
? Sans break, on « tombe » dans les cases suivants. Le mot-clé default couvre le cas restant.

Q: Quelle comparaison le switch utilise-t-il ? [cours]
+ Une comparaison lâche (==)
- Une comparaison stricte (===)
- Une comparaison par référence
- Aucune : il compare les types seulement
? C'est une raison de préférer match dans le code moderne.

Q: Avec la syntaxe alternative des gabarits, comment termine-t-on un bloc ouvert par « if (...): » ? [cours]
+ endif;
- end;
- fi;
- }
? Syntaxe alternative : if (...): ... elseif (...): ... else: ... endif; — de même foreach/endforeach, for/endfor, while/endwhile. Pratique dans le HTML.

Q: Quelles valeurs sont « falsy » en PHP ?
+ 0
+ ""
+ []
+ null
- "false"
- "0.0"
? "false" et "0.0" sont des chaînes non vides et différentes de "0" : elles sont vraies.

Q: Quelle mention ce code attribue-t-il à une note de 17 ?
|if ($note >= 10) {
|    $mention = 'Passable';
|} elseif ($note >= 14) {
|    $mention = 'Bien';
|} elseif ($note >= 16) {
|    $mention = 'Très bien';
|}
+ Passable : seule la première condition vraie est exécutée
- Très bien : PHP choisit la condition la plus précise
- Bien : PHP s'arrête toujours à la deuxième condition
- Aucune : plusieurs conditions vraies provoquent une erreur
? Les conditions sont testées dans l'ordre et la première vraie l'emporte. Il faut tester du seuil le plus exigeant au plus large : >= 16, puis >= 14, puis >= 10.

Q: Plusieurs remises peuvent se cumuler sur une même commande. Pourquoi écrire une suite de if indépendants plutôt qu'une chaîne if / elseif ?
+ Avec elseif, seule la première condition vraie serait appliquée
- Parce que elseif est nettement plus lent qu'une suite de if
- PHP interdit d'enchaîner plus de trois elseif à la suite
- Pour que les remises soient appliquées par ordre alphabétique
? Règles indépendantes (cumulables) : des if indépendants. Règles exclusives (une seule s'applique) : if / elseif / else, ou un match.

Q: Que produit ce code en PHP 8 ?
|echo $a ? 'x' : $b ? 'y' : 'z';
+ Une erreur fatale : un ternaire imbriqué doit être parenthésé
- 'x' si $a est vrai, sinon 'y' ou 'z' selon la valeur de $b
- Toujours 'z', car le ternaire est évalué de gauche à droite
- Un simple avertissement, puis l'affichage de la valeur 'y'
? Depuis PHP 8, a ? b : c ? d : e sans parenthèses est refusé dès la compilation (l'ancienne associativité à gauche surprenait tout le monde). On écrit a ? b : (c ? d : e), ou mieux un match.

Q: Que vaut $r après $r = 0 ?: 'vide'; ?
= vide
? ?: (opérateur « Elvis ») renvoie l'opérande de gauche s'il est truthy, sinon celui de droite. 0 est falsy, donc 'vide'. Avec 0 ?? 'vide', on obtiendrait 0 (?? ne teste que null et l'absence).

Q: Qu'affiche ce code ?
|$code = '2';
|echo match ($code) {
|    1 => 'un',
|    2 => 'deux',
|    default => 'autre',
|};
+ autre : match compare strictement, la chaîne '2' n'est pas l'entier 2
- deux : match convertit la chaîne en entier avant de comparer
- Une UnhandledMatchError, car aucun cas ne correspond exactement
- Rien : un match n'affiche rien sans instruction return
? match utilise ===. Avec un bras default, aucune erreur ; sans default, une valeur non prévue lève une UnhandledMatchError.

Q: Que se passe-t-il quand aucun bras d'un match ne correspond et qu'il n'y a pas de default ?
+ Une UnhandledMatchError est levée
- match renvoie null sans rien signaler
- match renvoie la valeur du premier bras
- Un simple avertissement est affiché
? C'est une sécurité : un cas oublié se voit immédiatement, au lieu de produire un résultat vide qui passerait inaperçu.

Q: Que produit ce code ?
|$ok = true and false;
|var_dump($ok);
+ bool(true) : = est prioritaire sur and, $ok reçoit donc true
- bool(false) : true and false vaut false
- NULL : l'opérateur and ne renvoie aucune valeur
- Une erreur de syntaxe : and n'existe pas en PHP
? and et or ont une priorité plus faible que l'affectation : le code équivaut à ($ok = true) and false. Dans les expressions, on utilise && et ||.

Q: Comment écrire en PHP « $age est compris entre 18 et 65 inclus » ?
+ if ($age >= 18 && $age <= 65)
- if (18 <= $age <= 65)
- if ($age >= 18 || $age <= 65)
- if ($age between 18 and 65)
? PHP n'enchaîne pas les comparaisons : 18 <= $age <= 65 est une erreur de syntaxe. Avec ||, toutes les valeurs seraient acceptées.

Q: Que vaut isset($a, $b) quand $a vaut 1 et $b vaut null ?
+ false : isset n'est vrai que si toutes les variables existent et ne valent pas null
- true : il suffit qu'une des deux variables soit définie
- 1 : isset renvoie le nombre de variables définies
- Une erreur : isset n'accepte qu'un seul argument
? isset accepte plusieurs arguments et les combine comme un ET. Une valeur null est considérée comme « non définie ».

# 03

Q: Que garantit une boucle do ... while ?
+ Le corps s'exécute au moins une fois
- Le corps ne s'exécute jamais si la condition est fausse
- Le corps s'exécute exactement deux fois
- La condition est testée avant le corps
? do ... while teste la condition après le corps. Un while peut s'exécuter zéro fois.

Q: Quelle est l'erreur de « décalage d'une unité » (off-by-one) ?
+ Une borne mal choisie (< au lieu de <=) : un tour de trop ou de moins
- Une variable dont le type change au milieu de la boucle
- Une boucle dont la condition ne devient jamais fausse
- Un tableau dont l'indice dépasse la taille déclarée
? Exemple : for ($i = 0; $i < 10; $i++) fait 10 tours (0 à 9), alors que $i <= 10 en ferait 11.

Q: Quelle différence entre break et continue ?
+ break quitte la boucle, continue passe à l'itération suivante
- break passe à l'itération suivante, continue quitte la boucle
- Ils sont identiques
- break arrête le script entier

Q: Quelle est la cause la plus fréquente d'une boucle infinie ?

- condition, puis init, puis évolution, à chaque tour de boucle
- évolution, condition, init, dans cet ordre exact à chaque tour
- init et évolution à chaque tour, condition évaluée une seule fois
? C'est l'équivalent d'un while avec l'initialisation avant et l'évolution à la fin du corps.

Q: Comment savoir, pendant une boucle, si une valeur a déjà été rencontrée ?

- Il trie les films par titre en ordre alphabétique
- Il trie les films par année décroissante, sur place

Q: Que fait array_slice($films, 0, 3) ? [cours]

- Trie seulement les trois premiers éléments du tableau

Q: Quelles fonctions modifient le tableau passé en argument (sur place) ?

- array_map

- array_slice

Q: Pourquoi ajouter array_values() après array_filter() ?

- array_filter supprime les clés texte des éléments conservés

- array_search renvoie toujours un booléen, jamais la clé trouvée
- if (array_search(...)) est une erreur de syntaxe depuis PHP 8

Q: Avec des clés texte communes, quelle différence entre array_merge($a, $b) et $a + $b ?

- array_merge : $a garde ses clés ; + : les valeurs de $b écrasent celles de $a
- Les deux additionnent les valeurs numériques des clés communes

Q: Que fait l'instruction [$a, $b] = [$b, $a]; ?

- Elle copie $a dans $b sans modifier $a
- Elle provoque une erreur de syntaxe

Q: Quelle différence y a-t-il entre sort() et asort() ?

- asort renumérote les clés ; sort conserve l'association clé → valeur

Q: Que produit [...$a, ...$b] quand $a = [1, 2] et $b = [3] ?

- À commenter plusieurs lignes de code en une seule fois
- À inclure le contenu d'un autre fichier dans le script

- Parce que != false lève une exception sur les chaînes UTF-8

Q: Que retourne mb_strpos($resume, 'équipage') quand le mot est absent ? [cours]

- -1
- 0
- null

Q: Que fait mb_substr($s, 1, -1) ?

- Retourne le dernier caractère
- Inverse la chaîne

- '75001' : la partie de la chaîne qui correspond

- Les accents, pour obtenir une chaîne ASCII

- Une fonction qui affiche son résultat avec echo

- Le dossier racine du disque

Q: Que permet l'appel formaterPrix(devise: '$', prix: 3.99) ?

- Forcer le typage strict sur chacun des deux arguments

- Oui, mais seulement celles déclarées avant la fonction

Q: À quoi sert require_once ? [cours]

- À charger un fichier en tâche de fond, sans bloquer le script
- À charger un fichier sans erreur même s'il est absent

Q: Avec function creerResumeCourt($resume, $limiteMots = 18), que vaut $limiteMots pour creerResumeCourt($texte) ? [cours]
= 18

Q: Quels sont les deux ingrédients indispensables d'une fonction récursive ?
+ Un cas de base et un pas récursif qui s'en rapproche
- Une boucle for et un compteur de profondeur global
- Une variable globale et un return en fin de fonction
- Un bloc try/catch et un bloc finally pour la pile
? Sans cas de base, les appels ne s'arrêtent jamais ; sans pas qui s'en rapproche, ils ne s'arrêtent pas non plus.

Q: Que se passe-t-il si une fonction récursive n'atteint jamais son cas de base ?
+ Les appels s'empilent jusqu'à épuiser la mémoire
- PHP s'arrête proprement et retourne null à l'appelant
- PHP convertit automatiquement la récursion en boucle
- Rien : la fonction retourne simplement la valeur 0
? Chaque appel consomme de la mémoire sur la pile d'appels.

Q: Que vaut 0! (factorielle de zéro) ?
= 1
? 0! = 1 par convention : c'est le cas de base d'une factorielle récursive (n! = n × (n-1)!).

Q: PHP optimise-t-il la récursion terminale (tail call optimization) ?
+ Non : chaque appel crée un nouveau cadre dans la pile
- Oui, toujours, quel que soit le type de récursion
- Oui, mais seulement quand strict_types est activé
- Oui, mais uniquement en ligne de commande (CLI)
? En PHP, une récursion très profonde peut épuiser la mémoire ; on préfère alors une version itérative.

Q: Pourquoi fib(30) récursif naïf est-il beaucoup plus lent que la version itérative ?
+ Les mêmes sous-problèmes sont recalculés un très grand nombre de fois
- Parce que la récursion est toujours plus lente qu'une boucle
- Parce que fib(30) dépasse la taille maximale d'un entier PHP
- Parce que PHP ralentit les fonctions qui s'appellent elles-mêmes
? fib(28) est calculé dans fib(30) et aussi dans fib(29)… fib(30) fait environ 2,7 millions d'appels contre 30 itérations.

Q: Quelle technique évite de recalculer les mêmes sous-problèmes d'une récursion ?
+ La mémoïsation : stocker les résultats déjà calculés
- La concaténation de chaînes entre chaque appel
- L'échappement HTML des résultats intermédiaires
- Le typage strict de tous les paramètres entiers
? Un tableau $memo[$n] consulté avant tout calcul transforme Fibonacci récursif en algorithme linéaire.

Q: Que retourne somme([1, [2, 3], [4, [5]]]) avec cette fonction ?

Q: Pour un palindrome récursif, quel est le cas de base ?

- Une chaîne de longueur 2

- Une chaîne dont le premier caractère est une voyelle

Q: Que fait use dans function ($prix) use ($taux) { … } ?

- Il importe une classe nommée $taux depuis un namespace
- Il rend $taux globale pour tout le reste du script
- Il déclare $taux comme second paramètre obligatoire
? Une closure ne voit pas les variables extérieures : use les capture (par valeur, au moment de la création ; use (&$taux) pour une référence). Une fonction fléchée fn capture automatiquement par valeur.

Q: Qu'affiche ce code ?

|$x = 10;

= 2
? Une fonction fléchée capture les variables PAR VALEUR au moment de sa création : $x valait 1. Modifier $x ensuite ne change rien pour $f.

Q: Que reçoit $nombres dans function somme(int ...$nombres) appelée avec somme(1, 2, 3) ?
+ Un tableau [1, 2, 3] : c'est un paramètre variadique
- Seulement 1 : les autres arguments sont ignorés
- Une chaîne « 1, 2, 3 » qu'il faut découper
- Une erreur : la fonction attend un seul argument

Q: Que change le & dans function ajouter(array &$t, int $v) ?
+ Le tableau est passé par référence : la fonction modifie l'original
- Le tableau est copié deux fois pour plus de sécurité
- Le paramètre devient facultatif, avec [] comme valeur par défaut
- Le tableau est converti en objet pendant l'appel

Q: Que retourne une fonction déclarée avec le type : void ?

- La valeur de la dernière instruction exécutée
- Un booléen qui indique si la fonction a réussi
? : void documente une fonction appelée pour son effet. return 5; y provoquerait une erreur de compilation.

Q: Que signifie le type de retour never (PHP 8.1) ?
+ La fonction ne rend jamais la main : elle lève une exception ou arrête le script
- La fonction ne doit jamais être appelée en production
- La fonction ne prend jamais de paramètre
- La fonction renvoie toujours null
? Exemple : une fonction rediriger() qui appelle header() puis exit, ou une fonction qui lève toujours une exception.

Q: Comment mesurer la durée d'exécution d'un bout de code PHP ?
+ Relever hrtime(true) avant et après, puis faire la différence (en nanosecondes)

Q: À quoi sert le bloc finally d'un try / catch ?
+ Il s'exécute toujours, qu'une exception ait été levée ou non
- Il s'exécute seulement si une exception est levée
- Il remplace le catch
- Il s'exécute avant le try

Q: Quelle interface est commune à Exception et à Error ?
= Throwable
? Tout ce qu'on peut lancer avec throw implémente Throwable. catch (Throwable $e) attrape donc tout, y compris les Error.

Q: Quelle différence y a-t-il entre Exception et Error en PHP 8 ?
+ Error signale des fautes de programmation ; Exception, des situations prévues par le code
- Exception est réservée au moteur PHP ; Error aux classes du développeur
- Error ne peut jamais être attrapée par un catch, contrairement à Exception
- Aucune différence : Error n'est qu'un autre nom de la classe Exception
? TypeError, ArgumentCountError ou DivisionByZeroError héritent de Error. Elles signalent un bug à corriger plutôt qu'un cas métier à gérer.

Q: Ce catch attrape-t-il l'erreur ?
|try {
|    strlen();
|} catch (Exception $e) {
|    echo 'attrapée';
|}
+ Non : ArgumentCountError hérite de Error, pas de Exception
- Oui : en PHP 8, toutes les erreurs sont des Exception
- Oui, mais seulement si display_errors vaut 1
- Non : strlen() sans argument renvoie simplement 0
? Le script s'arrête sur « Uncaught ArgumentCountError ». Pour l'attraper il faudrait catch (Error $e) ou catch (Throwable $e) — mais une telle erreur se corrige plutôt dans le code.

Q: Comment attraper deux types d'exception avec le même bloc de traitement ?

- catch (InvalidArgumentException && RuntimeException $e)
- catch ([$e1, $e2] => InvalidArgumentException, RuntimeException)

- Il affecte null à $nom, puis lève l'exception plus tard
? Depuis PHP 8, throw est une expression : on peut l'utiliser après ??, ?: ou dans une fonction fléchée.

Q: Quelle exception standard lever quand une fonction reçoit un argument invalide (par exemple un âge négatif) ?
+ InvalidArgumentException
- PDOException
- DivisionByZeroError
- JsonException
? InvalidArgumentException (famille LogicException) indique que l'appelant a mal utilisé la fonction. RuntimeException convient aux problèmes détectés à l'exécution (fichier illisible, service indisponible).

Q: Comment créer sa propre exception métier ?

- function StockInsuffisantException(): Throwable {}

- La fonction retourne null sans aucun message

Q: Pourquoi éviter l'opérateur @, comme dans @file_get_contents($chemin) ?

- Il transforme l'avertissement en exception non attrapée
- Il est interdit depuis PHP 8 et provoque une erreur de syntaxe

- display_errors = On, pour aider les visiteurs
- error_reporting = 0, pour ne plus rien journaliser
? Les erreurs ne doivent jamais apparaître dans la page (fuite d'informations) mais doivent être enregistrées dans un journal pour être corrigées.

- PHP relance automatiquement la fonction qui a échoué

Q: Dans un catch, que fait l'instruction throw $e; ?
+ Elle relance la même exception vers l'appelant après un traitement local
- Elle supprime l'exception et reprend l'exécution normalement
- Elle crée une copie de l'exception avec un nouveau message
- Elle affiche l'exception puis arrête le serveur web

- Dans un cookie, pour le retrouver à la visite suivante
- Dans l'URL de redirection, pour faciliter le débogage
