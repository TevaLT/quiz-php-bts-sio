# 00

Q: Où le code PHP est-il exécuté quand une page est demandée ?
+ Sur le serveur, avant l'envoi de la réponse au navigateur
- Dans le navigateur, juste après le chargement de la page
- Sur le poste de l'utilisateur, grâce à un moteur intégré
- Dans la base de données, au moment de la requête SQL
? PHP est un langage exécuté côté serveur : le navigateur ne reçoit que le résultat (généralement du HTML), jamais le code PHP.

Q: Dans « Afficher le code source » du navigateur, que voit-on d'un script PHP ?
+ Uniquement le HTML produit, jamais les balises <?php
- Le code PHP complet, avec ses variables et ses commentaires
- Le code PHP, mais avec la valeur des variables à la place des noms
- Seulement les commentaires PHP laissés par le développeur
? Le serveur exécute le PHP et n'envoie que le résultat : le code source reste côté serveur.

Q: Que fait la commande « php -l fichier.php » ?
+ Elle vérifie la syntaxe (lint) sans exécuter le script
- Elle exécute le script en affichant chaque ligne traitée
- Elle liste tous les fichiers PHP présents dans le dossier
- Elle démarre un serveur local pour ce fichier précis
? « -l » signifie lint : PHP analyse la syntaxe et signale les erreurs sans rien exécuter. À lancer sur chaque fichier avant de le rendre ou de le publier.

Q: Quelle commande démarre le serveur web intégré de PHP sur le port 8000 ?
+ php -S localhost:8000
- php serve localhost:8000
- php --run 8000
- php -L localhost:8000
? « php -S adresse:port » (S majuscule) lance le serveur de développement. Option « -t dossier » pour choisir la racine (ex : -t public).

Q: Quelle option de la commande php vérifie la syntaxe d'un fichier ? (un tiret et une lettre)
= -l | l
? php -l fichier.php : lint, vérification de syntaxe sans exécution.

Q: Que produit <?= $titre ?> ?
+ La même chose que <?php echo $titre; ?>
- La même chose que <?php return $titre; ?>
- La même chose que <?php var_dump($titre); ?>
- Une erreur : la balise n'existe plus
? <?= expression ?> est le raccourci d'écriture de echo, très utilisé dans les gabarits HTML.

Q: Quel opérateur concatène deux chaînes en PHP ?
+ Le point (.)
- Le plus (+)
- L'esperluette (&)
- Le double deux-points (::)
? En PHP la concaténation est le point. Le + est arithmétique : avec une chaîne non numérique il lève un TypeError en PHP 8.

Q: Un point-virgule oublié à la fin d'une instruction provoque généralement…
+ Une « Parse error » souvent signalée à la ligne suivante
- Un « Warning: Undefined variable » à la ligne de l'oubli
- Une réponse HTTP 404 renvoyée par le serveur intégré
- Aucune erreur : PHP rajoute le point-virgule tout seul
? PHP lit l'instruction suivante comme la suite de la précédente et détecte l'erreur une ligne plus loin : on regarde la ligne signalée ET celle d'avant.

Q: Que signifie « Warning: Undefined variable $age » ?
+ $age est utilisée avant d'avoir reçu une valeur
- $age a reçu une valeur d'un type incompatible
- $age est déclarée mais n'est jamais affichée
- $age porte le même nom qu'une fonction existante
? Une variable doit être affectée avant d'être lue.

Q: Dans un fichier qui ne contient que du PHP, que fait-on de la balise fermante ?
+ On l'omet, pour ne pas envoyer d'espace parasite
- On la place toujours, sinon le fichier ne s'exécute pas
- On la remplace par une balise de fermeture <?end>
- On la met en première ligne, avant la balise ouvrante
? Un espace ou un retour à la ligne après ?> serait envoyé au navigateur, donc avant les en-têtes HTTP.

Q: PHP signale une erreur de syntaxe à la ligne 12. Où commencer à chercher ?
+ Ligne 12 et la ligne juste avant
- Uniquement à la ligne 12, jamais ailleurs
- Dans la feuille de style CSS du site
- Dans le fichier de configuration php.ini
? Méthode de débogage : lire le message en entier, noter le type d'erreur, regarder la ligne signalée et la précédente, corriger une seule chose à la fois.

Q: Que contient la constante prédéfinie PHP_VERSION ?
+ La version de PHP qui exécute le script
- La version du navigateur de l'utilisateur
- La version du serveur de base de données
- La version du système d'exploitation hôte
? PHP_VERSION permet par exemple d'afficher dans la page la version de PHP qui exécute le script.

Q: Parmi ces situations, lesquelles provoquent une erreur ou un avertissement PHP ?
+ Un guillemet ouvert jamais refermé
+ Utiliser $x avant de lui avoir donné une valeur
- Écrire un commentaire avec //
- Mettre un espace avant le signe =
? Une chaîne non fermée donne une Parse error ; une variable non définie donne un Warning. Les commentaires et les espaces sont inoffensifs.

# 01

Q: Quel est le type de la valeur 8.5 en PHP ?
+ float
- int
- string
- decimal
? Les nombres à virgule sont des float et s'écrivent avec un point décimal (jamais une virgule).

Q: Pourquoi stocker l'année 1979 comme entier plutôt que comme la chaîne "1979" ?
+ Un entier se compare, se trie et se calcule correctement
- PHP interdit de mettre des chiffres entre guillemets
- Une chaîne est trop lente pour être affichée avec echo
- Un entier prend moins de place qu'une chaîne en base
? Les types portent du sens : on veut pouvoir faire $annee >= 1990 ou $annee + 1. Une chaîne se trierait alphabétiquement.

Q: Pourquoi le prix doit-il valoir 3.99 plutôt que "3,99 €" ?
+ Le symbole et la virgule sont de l'affichage, pas de la donnée
- PHP refuse d'enregistrer un symbole monétaire dans une variable
- La virgule est réservée à la séparation des éléments d'un tableau
- Un float prend toujours moins de place qu'une chaîne en mémoire
? Règle d'or : calculer avec des nombres, formater (number_format) uniquement au moment de l'affichage.

Q: Que produit var_dump("1979"); ?
+ string(4) "1979"
- int(1979)
- string(1979)
- float(1979)
? var_dump affiche le type ET la valeur. Les guillemets font de 1979 une chaîne de 4 caractères.

Q: Que produit var_dump(10 / 2); en PHP 8 ?
+ int(5)
- float(5)
- int(2)
- string(1) "5"
? L'opérateur / renvoie un int quand la division tombe juste (10 / 2) et un float sinon (7 / 2 donne float(3.5)).

Q: Que retourne intdiv(7, 2) ?
= 3
? intdiv renvoie le quotient entier (7 = 2 × 3 + 1).

Q: Que vaut 2 ** 10 ?
= 1024
? ** est l'opérateur de puissance (2 puissance 10).

Q: Que produit ce code ?
|$n = 'Ada';
|echo 'Bonjour $n';
+ Bonjour $n
- Bonjour Ada
- Bonjour
- Une erreur
? Entre guillemets simples, il n'y a pas d'interpolation. Avec des guillemets doubles, "Bonjour $n" donnerait « Bonjour Ada ».

Q: Que fait declare(strict_types=1); placé en tête d'un fichier ?
+ Il refuse les conversions implicites de type lors des appels (TypeError)
- Il active l'affichage détaillé de toutes les erreurs et avertissements
- Il impose de déclarer le type de chaque variable du fichier
- Il bloque l'usage des chaînes de caractères dans les calculs
? Sans lui, f("5") pour un paramètre int est converti silencieusement ; avec lui, c'est un TypeError. Cela évite des bugs discrets.

Q: Que vaut 0.1 + 0.2 === 0.3 en PHP ?
+ false
- true
- null
- Une erreur de syntaxe
? Les float sont stockés en binaire et 0.1 + 0.2 donne 0.30000000000000004. Pour comparer des float, on utilise une tolérance ; pour l'argent, on travaille en centimes (entiers).

Q: Que retourne (int) "12abc" ?
= 12
? Le cast lit les chiffres du début de la chaîne et s'arrête au premier caractère non numérique.

Q: Laquelle de ces valeurs est considérée comme vraie (truthy) dans une condition ?
+ "false" (la chaîne de texte)
- "0" (la chaîne zéro)
- [] (le tableau vide)
- 0.0 (le flottant nul)
? Sont « falsy » : false, 0, 0.0, "", "0", [] et null. La chaîne "false" est une chaîne non vide et différente de "0" : elle est vraie.

Q: Que se passe-t-il avec intdiv(1, 0) ?
+ Une DivisionByZeroError est lancée
- Le résultat vaut 0
- Le résultat vaut INF
- Un simple avertissement apparaît
? En PHP 8, la division par zéro (/, intdiv, %) lance une DivisionByZeroError.

Q: Quelles valeurs sont de type float ?
+ 8.5
+ 1e3
- "8.5"
- 8
? 1e3 vaut 1000.0 (notation scientifique, float). "8.5" est une chaîne, 8 est un entier.

Q: $Titre et $titre désignent…
+ Deux variables distinctes : la casse compte
- La même variable : PHP ignore la casse des noms
- La même variable, avec un avertissement à l'affichage
- Une erreur de syntaxe qui arrête le script
? Les noms de variables sont sensibles à la casse (les noms de fonctions ne le sont pas).

Q: Que retourne number_format(1234.5, 2, ',', ' ') ?
+ 1 234,50
- 1,234.50
- 1234.5
- 1.234,5
? number_format(nombre, décimales, séparateur décimal, séparateur de milliers).

Q: Une bobine 35 mm défile à 24 images par seconde, une image occupe environ 19 mm. Environ quelle longueur pour 117 minutes ?
+ Environ 3,2 km
- Environ 320 m
- Environ 32 km
- Environ 3,2 m
? 117 × 60 = 7 020 s ; × 24 = 168 480 images ; × 19 mm = 3 201 120 mm ≈ 3,2 km.

Q: 37 places à 7,50 €, dont 12 avec une réduction de 20 %. Quel est le montant total ?
+ 259,50 €
- 277,50 €
- 222,00 €
- 237,60 €
? 25 × 7,50 + 12 × (7,50 × 0,80) = 187,50 + 72 = 259,50 €. Plein tarif partout : 277,50 € (écart 18 €).

Q: Que fait $nombreFilms++; ? [cours]
+ Il ajoute 1 à $nombreFilms (comme $nombreFilms = $nombreFilms + 1)
- Il double la valeur de $nombreFilms à chaque exécution du script
- Il crée une copie indépendante de la variable $nombreFilms
- Il affiche la valeur de $nombreFilms puis supprime la variable
? ++ est l'opérateur d'incrémentation ; -- décrémente ; += ajoute une valeur quelconque.

Q: Avec $dureeMinutes = 117, que valent $heures = (int) ($dureeMinutes / 60); et $minutes = $dureeMinutes % 60; ? [cours]
+ 1 heure et 57 minutes
- 2 heures et 3 minutes
- 1 heure et 17 minutes
- 117 heures et 0 minute
? 117 / 60 = 1,95 → (int) tronque à 1 ; 117 % 60 = 57 (reste de la division).

# 02

Q: Dans appreciationFilm, que renvoie la note 8,49 ?
+ Très bon
- Exceptionnel
- Intéressant
- À redécouvrir
? Exceptionnel commence à 8,5 (inclus) ; 8,49 est juste en dessous, donc Très bon (≥ 7).

Q: Pourquoi teste-t-on les seuils du plus exigeant au plus large dans appreciationFilm ?
+ Un test large placé en premier « avalerait » les notes élevées
- PHP évalue les conditions dans l'ordre inverse de leur écriture
- Cela économise de la mémoire pendant l'exécution du script
- Un elseif placé avant un if provoque une erreur de syntaxe
? Les conditions sont évaluées dans l'ordre ; la première vraie gagne. Un test large placé en premier « avale » les cas plus exigeants.

Q: Quelle différence entre == et === ?
+ === compare aussi le type, == fait des conversions
- Aucune, ce sont des synonymes
- == compare les types, === compare les valeurs
- === ne s'applique qu'aux chaînes
? Préférer === pour éviter les conversions surprenantes (voir le piège 0 == "a").

Q: Que affiche echo 2 <=> 5; ?
= -1
? L'opérateur « vaisseau spatial » renvoie -1, 0 ou 1 selon que le premier opérande est plus petit, égal ou plus grand. Très utile dans usort.

Q: Dans if (isset($t['x']) && $t['x'] > 3), que se passe-t-il si la clé 'x' est absente ?
+ La 2e condition est ignorée (évaluation paresseuse) : aucun Warning
- Un Warning « Undefined array key » apparaît à la 2e condition
- Une exception TypeError est levée avant la fin du test
- La condition entière est considérée comme vraie par défaut
? && s'arrête dès qu'un opérande est faux. D'où l'habitude de placer isset() en premier.

Q: Quelle différence entre match et switch ?
+ match compare en strict, renvoie une valeur et lève UnhandledMatchError sans cas
- match compare en lâche (==) comme switch, mais avec une syntaxe plus courte
- match n'accepte que des chaînes et exige un break après chaque cas
- match s'exécute plus lentement mais gère le fall-through automatiquement
? match est une expression, plus sûre : pas de fall-through, comparaison stricte, erreur si cas oublié (sans default).

Q: Pourquoi dresser un tableau de décision avant de coder le calcul du tarif ?
+ Pour repérer les frontières (17/18 ans, 64/65 ans) et les règles contradictoires
- Parce que PHP refuse d'exécuter un if sans tableau de décision préalable
- Pour que le script s'exécute plus rapidement lors de chaque requête
- Pour pouvoir se dispenser d'écrire des tests unitaires par la suite
? Une décision applique exactement les règles écrites, y compris leurs trous et chevauchements : on les repère sur papier avant.

Q: Pourquoi utilise-t-on plusieurs if et non une chaîne if / elseif pour attribuer des badges ?
+ Un film peut cumuler plusieurs badges, alors qu'elseif s'arrête au premier
- Parce que elseif est nettement plus lent qu'une suite de if
- PHP interdit d'employer elseif quand on construit un tableau
- Pour que les badges soient triés par ordre alphabétique
? Règles indépendantes = if indépendants. Règles exclusives (une seule application) = if / elseif / else.

Q: Que retourne empty("0") ?
+ true
- false
- Une erreur
- null
? La chaîne "0" est falsy, donc empty() la considère comme vide. Attention aux champs de formulaire contenant un 0 légitime.

Q: Que affiche echo 0 ?? 'x'; ?
= 0
? ?? ne remplace la valeur que si elle est absente ou null. 0 est conservé (contrairement à l'opérateur ?: qui testerait la « falsyté » et donnerait 'x').

Q: Dans un switch, que se passe-t-il si un case n'a pas de break ? [cours]
+ L'exécution continue dans le case suivant (fall-through)
- PHP signale une erreur de syntaxe et arrête le script
- Le switch s'arrête quand même à la fin de ce case
- Le case suivant est ignoré et PHP passe au default
? Sans break, on « tombe » dans les cases suivants. Le mot-clé default couvre le cas restant.

Q: Quelle comparaison le switch utilise-t-il ? [cours]
+ Une comparaison lâche (==)
- Une comparaison stricte (===)
- Une comparaison par référence
- Aucune : il compare les types seulement
? C'est une raison de préférer match dans le code moderne.

Q: Avec la syntaxe alternative des gabarits, comment termine-t-on un bloc ouvert par « if (...): » ? [cours]
+ endif;
- end;
- fi;
- }
? Syntaxe alternative : if (...): ... elseif (...): ... else: ... endif; — de même foreach/endforeach, for/endfor, while/endwhile. Pratique dans le HTML.

Q: Quelles valeurs sont « falsy » en PHP ?
+ 0
+ ""
+ []
+ null
- "false"
- "0.0"
? "false" et "0.0" sont des chaînes non vides et différentes de "0" : elles sont vraies.

Q: Une personne de 17 ans non membre : quel tarif (règles : plein 9 €, moins de 18 ans 6 €, 65 ans et plus 7 €, membre -2 €) ?
+ 6 €
- 9 €
- 4 €
- 7 €
? Moins de 18 ans : 6 €. Membre : 4 €. À 18 ans : 9 € (7 € pour un membre).

# 03

Q: Que garantit une boucle do ... while ?
+ Le corps s'exécute au moins une fois
- Le corps ne s'exécute jamais si la condition est fausse
- Le corps s'exécute exactement deux fois
- La condition est testée avant le corps
? do ... while teste la condition après le corps. Un while peut s'exécuter zéro fois.

Q: Quelle est l'erreur de « décalage d'une unité » (off-by-one) ?
+ Une borne mal choisie (< au lieu de <=) : un tour de trop ou de moins
- Une variable dont le type change au milieu de la boucle
- Une boucle dont la condition ne devient jamais fausse
- Un tableau dont l'indice dépasse la taille déclarée
? Exemple : for ($i = 0; $i < 10; $i++) fait 10 tours (0 à 9), alors que $i <= 10 en ferait 11.

Q: Quelle différence entre break et continue ?
+ break quitte la boucle, continue passe à l'itération suivante
- break passe à l'itération suivante, continue quitte la boucle
- Ils sont identiques
- break arrête le script entier
? continue est pratique pour ignorer un élément filtré sans imbriquer des if.

Q: Dans foreach ($films as $cle => $film), que contient $cle ?
+ La clé (index ou nom de clé) de l'élément courant
- La clé de l'élément qui précède l'élément courant
- Le nombre d'éléments qu'il reste encore à parcourir
- Toujours un entier compris entre 0 et n-1
? Pour un tableau associatif, $cle contient le nom de la clé.

Q: Pourquoi tester « multiple de 15 » avant « multiple de 3 » dans FizzBuzz ?
+ Sinon 15 afficherait « Fizz » et n'atteindrait jamais « FizzBuzz »
- Parce que 15 est un nombre premier qu'il faut traiter à part
- Parce que PHP évalue les conditions de bas en haut du fichier
- Pour que la boucle s'arrête plus tôt et gagne du temps
? L'ordre des conditions compte : le cas le plus spécifique (3 ET 5) doit passer en premier.

Q: Que retourne suiteCollatz(6) ?
+ [6, 3, 10, 5, 16, 8, 4, 2, 1]
- [6, 3, 1]
- [6, 12, 6, 3]
- [1, 2, 4, 8, 16, 5, 10, 3, 6]
? 6 est pair → 3 ; 3 est impair → 10 ; 10 → 5 ; 5 → 16 ; 16 → 8 → 4 → 2 → 1.

Q: Que doit faire suiteCollatz(0) ?
+ Lancer une InvalidArgumentException (entier >= 1 attendu)
- Retourner le tableau [0] sans autre vérification
- Boucler indéfiniment faute d'atteindre jamais la valeur 1
- Retourner un tableau vide pour signaler l'absence de suite
? On refuse les entrées invalides plutôt que de produire une boucle infinie ou un résultat absurde.

Q: Que dit-on de la conjecture de Collatz ?
+ Personne n'a prouvé que toute suite atteint 1, même si c'est vérifié très loin
- Elle a été démontrée en 1937 par Lothar Collatz lui-même, en trois pages
- Elle est réfutée par un contre-exemple découvert grâce aux ordinateurs
- Elle ne s'applique qu'aux nombres pairs, les impairs étant exclus
? Lothar Collatz l'étudie en 1937 ; elle reste ouverte malgré sa simplicité apparente.

Q: Comment détecter un cycle dans une suite sans supposer qu'elle atteint 1 ?
+ Mémoriser les valeurs déjà vues et faire break dès qu'une réapparaît
- Limiter la boucle à cent tours puis supposer qu'il y a un cycle
- Utiliser un do ... while dont la condition est toujours vraie
- Trier la suite avec sort() puis comparer le premier et le dernier terme
? Un tableau $vus[$n] = true et isset($vus[$n]) détectent la répétition.

Q: Quelle est la cause la plus fréquente d'une boucle infinie ?
+ L'état testé par la condition ne progresse jamais vers l'arrêt
- L'emploi d'un compteur nommé $i au lieu d'un nom explicite
- L'absence d'un break à l'intérieur du corps de la boucle
- Un tableau trop volumineux pour tenir en mémoire
? Une boucle doit progresser : oublier $i++ dans un while est le classique.

Q: Dans for (init; condition; évolution), dans quel ordre les parties s'exécutent-elles ?
+ init une fois, puis condition avant chaque tour, évolution après chaque tour
- condition, puis init, puis évolution, à chaque tour de boucle
- évolution, condition, init, dans cet ordre exact à chaque tour
- init et évolution à chaque tour, condition évaluée une seule fois
? C'est l'équivalent d'un while avec l'initialisation avant et l'évolution à la fin du corps.

Q: Combien de fois le corps d'un while s'exécute-t-il si sa condition est fausse dès le départ ? [cours]
= 0
? while teste avant d'exécuter : si c'est faux d'emblée, le corps ne s'exécute jamais.

Q: Que affiche for ($compteur = 5; $compteur >= 1; $compteur--) { echo $compteur; } ? [cours]
+ 54321
- 12345
- 543210
- 4321
? On part de 5 et on décrémente tant que $compteur >= 1 : le 0 n'est pas affiché.

Q: Quelle syntaxe produit une liste d'articles dans un gabarit HTML, avec une boucle ? [cours]
+ <?php foreach ($titres as $titre): ?> ... <?php endforeach; ?>
- <?php foreach $titres as $titre ?> ... <?php end; ?>
- <?php for each ($titres): ?> ... <?php endfor; ?>
- <?php loop ($titres): ?> ... <?php endloop; ?>
? La syntaxe alternative (deux-points + endforeach;) est très lisible quand on alterne PHP et HTML. Le bloc HTML n'est écrit qu'une fois.

Q: Que fait « continue; » dans une boucle foreach ? [cours]
+ Il passe à l'élément suivant sans exécuter la fin du corps
- Il quitte la boucle et reprend après l'accolade fermante
- Il relance la boucle depuis le premier élément du tableau
- Il met le script en pause jusqu'à la prochaine requête
? Exemple du MOOC : si le titre ne contient pas la recherche, on fait continue pour ne pas l'afficher.

# 04

Q: Quelle est la différence entre un tableau indexé et un tableau associatif ?
+ L'un utilise des clés numériques (0, 1, 2…), l'autre des clés nommées
- L'un est immuable une fois créé, l'autre peut être modifié
- L'un ne contient que des nombres, l'autre uniquement des chaînes
- L'un se parcourt avec for, l'autre uniquement avec foreach
? En réalité PHP n'a qu'un seul type (array) ; on parle d'indexé ou d'associatif selon les clés utilisées.

Q: Que retourne sort($titres) ?
+ true (le tableau est trié sur place)
- Le tableau trié, sous la forme d'un nouveau tableau
- Le nombre d'éléments qui ont changé de position
- null, car la fonction ne renvoie jamais rien
? sort modifie le tableau passé en paramètre et renvoie un booléen. Pour garder l'original : trier une copie.

Q: Pourquoi array_values(array_unique($t)) plutôt que seulement array_unique($t) ?
+ array_unique garde les clés d'origine ; array_values renumérote
- array_unique ne supprime pas réellement les doublons du tableau
- array_values trie les valeurs restantes par ordre croissant
- array_unique modifie le tableau d'origine et pas une copie
? Après array_unique ou array_filter, les clés peuvent présenter des « trous » (0, 2, 3…). array_values renumérote de 0 à n-1.

Q: Que retourne strlen("é") (fichier en UTF-8) ?
= 2
? strlen compte des octets ; « é » occupe 2 octets en UTF-8. mb_strlen("é") vaut 1.

Q: Pourquoi utiliser mb_strlen plutôt que strlen pour la règle « de 2 à 60 caractères » ?
+ mb_strlen compte les caractères (accents compris), strlen les octets
- mb_strlen s'exécute plus vite que strlen sur de longues chaînes
- strlen est obsolète et supprimée du langage depuis PHP 8.0
- mb_strlen retire automatiquement les espaces en début de chaîne
? Un prénom « Éloïse » ferait 8 octets mais 6 caractères. Les règles de longueur se calculent en caractères.

Q: À quoi sert le troisième paramètre de in_array($v, $tableau, true) ?
+ Il active la comparaison stricte (valeur ET type)
- Il trie le tableau avant la recherche
- Il retourne la position
- Il rend la recherche insensible à la casse
? Sans lui, in_array("abc", [0]) pouvait être vrai à cause des conversions. Toujours le mettre à true pour les listes blanches.

Q: Avec $film = ['resume' => null], que valent array_key_exists('resume', $film) et isset($film['resume']) ? [cours]
+ true et false
- true et true
- false et false
- false et true
? array_key_exists teste l'existence de la clé (même si la valeur est null) ; isset est faux pour une valeur null.

Q: Combien d'éléments contient explode(", ", "Science-fiction, Drame, Aventure") ? [cours]
= 3
